# Contributing

## Setup

```bash
npm install
npm run dev
```

The demo is `index.html`. Library source lives in `src/`.

```bash
npm run build
```

## Pull requests

- Keep the public API stable (`createDatePicker`, `dru-date-picker` attributes, Vue / React / Next / Nuxt entries).
- Do not add dependencies unless they are required.
- Match the existing code style.

Open an issue first for large changes.
